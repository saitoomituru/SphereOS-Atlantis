# 6xx product family

`products/`は共通packagesを異なるPresentation／Hostへ束ねる製品棚です。

| product | 主な操作面 | 現在地 |
|---|---|---|
| `spheredos-server` | Bash／CLI／CI／daemon候補 | `SCAFFOLDED / RUNTIME NOT IMPLEMENTED` |
| `spheredos-code` | VS Code Cockpit GUI候補 | `SCAFFOLDED / GUI NOT IMPLEMENTED` |

一般業務向けOpen Inspector、生活支援向けPostPet、third-party Presentationはここへ将来追加できます。
SphereDOS二製品だけを6xx familyの全体へ固定しません。
